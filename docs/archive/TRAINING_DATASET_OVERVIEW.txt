GARDE-FOUS
══════════

✅ Mode Strict (par défaut)
├─ Règle : Utiliser UNIQUEMENT docs sources
├─ Si non trouvé → "Non renseigné"
├─ Pas d'invention, déduction, supposition
└─ Citations obligatoires (doc + snippet)

✅ Détection Hallucinations
├─ Patterns : "je ne trouve pas", etc.
├─ Longueur anormale (< 10 chars)
├─ Absence citations
└─ Confiance faible (< 0.3)

✅ Traçabilité
├─ debug.json : preuves complètes
├─ metrics.json : qualité/confiance
└─ validation.json : GO/NO_GO/DRAFT


MÉTRIQUES CLÉS
══════════════

Training:
├─ gold_detection_rate    : % clients avec GOLD
├─ pipeline_ready_rate    : % clients exploitables
├─ avg_sources           : Moyenne fichiers/client
└─ extensions_distribution : {.docx: X, .pdf: Y}

Test Client:
├─ required_coverage     : % champs obligatoires
├─ weighted_coverage     : % champs totaux
├─ quality_score         : Score global (0-1)
├─ avg_confidence        : Confiance moyenne (0-1)
└─ status                : GO / NO_GO / DRAFT
